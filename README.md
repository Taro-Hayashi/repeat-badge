# BOOTH Badge

BOOTH Badgeのサポート・プライバシーページ用リポジトリです。

Mac・iPhone・iPadのSafari向けに、QRコード発行済みフィルタとリピーターバッジを統合した無料の非公式ツールを開発しています。App Storeではまだ公開していません。

- [サポート](https://taro-hayashi.github.io/booth-badge/)
- [プライバシーポリシー](https://taro-hayashi.github.io/booth-badge/privacy.html)
- [お問い合わせ・不具合報告](https://github.com/Taro-Hayashi/booth-badge/issues)

注文番号、購入者情報、ログイン情報を公開投稿へ含めないでください。
