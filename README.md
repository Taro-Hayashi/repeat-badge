# 注文バッジ

注文バッジのサポート・プライバシーページ用リポジトリです。

Mac・iPhone・iPadのSafari向けに、QRコード発行済みフィルタとリピーターバッジを統合した無料の非公式ツールを開発しています。App Storeではまだ公開していません。

- [サポート](https://tarohayashi.com/badge/)
- [プライバシーポリシー](https://tarohayashi.com/badge/privacy.html)
- [お問い合わせ・不具合報告](https://github.com/Taro-Hayashi/repeat-badge/issues)

注文番号、購入者情報、ログイン情報を公開投稿へ含めないでください。

このリポジトリには公開ページのソースを掲載しています。拡張機能本体の配布リポジトリではありません。

対象サービスの運営会社による提供・承認を受けたものではありません。
